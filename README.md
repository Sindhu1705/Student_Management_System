# 🎓 Grading Automation & Student Feedback Portal

A **full-stack application** built to streamline grading workflows and enhance student–faculty interactions.  
This system automates assignment evaluation, provides real-time feedback notifications, and reduces manual workload for faculty, while improving transparency and efficiency for students.  

---

## 🚀 Features
- **Automated Grading Workflows:** Handles assignments, lab reports, and exams with minimal manual effort.  
- **Student Feedback Management:** Provides instant visibility into performance and feedback.  
- **Real-Time Notifications:** Uses **Apache Kafka** to deliver grade updates instantly.  
- **Cloud Deployment:** Deployed on **AWS EC2** with containerized services via Docker.  
- **Efficiency Gains:** Reduced grading effort by 40% and streamlined evaluation processes.  

---

## 🛠️ Tech Stack
**Frontend:** Angular 16, TypeScript, HTML5, CSS3  
**Backend:** Spring Boot, REST APIs  
**Database:** MySQL  
**Messaging:** Apache Kafka  
**DevOps / Cloud:** Docker, AWS EC2
